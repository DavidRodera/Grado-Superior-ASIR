Lección 1: Modelo de Cajas - Fundamento del Diseño Web

Nivel Esencial

📚 ¿Qué es el Modelo de Cajas?

Todo elemento HTML es una caja rectangular compuesta por 4 capas:

Margin (margen exterior)
Border (borde)
Padding (margen interior)
Content (contenido)

📏 Dimensiones del Contenido

width: 200px;
height: 150px;

min-width, max-height para límites

↔️ Márgenes

margin: 20px;
margin: 10px 20px 30px 40px;

Valores: superior, derecha, inferior, izquierda

📐 Padding

padding: 15px;
padding-top: 10px;

Espacio interno entre contenido y borde

🖼️ Bordes

border: 2px solid #000;
border-radius: 10px;

border-style: solid, dashed, dotted

💡 ¡Cálculo importante! Ancho total = width + padding + border + margin. Con box-sizing: border-box el ancho incluye padding y border.

Lección 2: Selectores Avanzados - Precisión en el Estilo

Nivel Intermedio

📚 Selectores Específicos

👨‍👦 Selector de Hijos Directos

p > .destacado { color: purple; }

Selecciona solo elementos con clase "destacado" que sean hijos DIRECTOS de <p>

👥 Selector de Hermanos Adyacentes

h1 + p { text-indent: 2.5em; }

Afecta al primer <p> que sigue inmediatamente a un <h1>

🎯 Selectores de Atributos

a[href="http://google.com"] { color: red; }

Selecciona enlaces con URL exacta a Google

🎭 Pseudo-clases y Pseudo-elementos

:link (no visitado) :visited (visitado) :hover (ratón encima)

🔗 Pseudo-clases de Enlace

a:link { color: blue; }
a:visited { color: purple; }
a:hover { font-weight: bold; }
a:active { color: red; }

👶 Selectores de Posición

p:first-child { color: blue; }
p:last-child { color: red; }
p:nth-child(3) { background: yellow; }

📝 Pseudo-elementos

p::first-letter { font-size: 2em; }
p::first-line { font-weight: bold; }
p::before { content: "📌 "; }
💡 Orden importante: Para enlaces, sigue este orden: :link → :visited → :hover → :active (LoVe HAte)

Lección 4: Flexbox - Diseño Flexible

Nivel Avanzado

📚 ¿Qué es Flexbox?

Flexbox (Flexible Box) es un modelo de diseño CSS que facilita la creación de diseños flexibles. Permite alinear y distribuir elementos dentro de un contenedor de manera eficiente en una sola dimensión (horizontal o vertical).

🎯 Conceptos Clave

Contenedor Flex: Elemento padre con display: flex

Items Flex: Elementos hijos directos del contenedor

Eje Principal: Dirección principal (row o column)

Eje Cruzado: Dirección perpendicular al eje principal

🎪 Activación de Flex

.contenedor { display: flex; /* Elemento de bloque */ } .contenedor-inline { display: inline-flex; /* Elemento en línea */ }

🔧 Propiedades del Contenedor

Item 1
Item 2
Item 3

📏 flex-direction

flex-direction: row; /* Horizontal */ flex-direction: column; /* Vertical */ flex-direction: row-reverse; flex-direction: column-reverse;

Define la dirección del eje principal

🔄 flex-wrap

flex-wrap: nowrap; /* Una línea */ flex-wrap: wrap; /* Múltiples líneas */ flex-wrap: wrap-reverse;

Controla si los items pueden saltar de línea

🎯 justify-content

justify-content: flex-start; justify-content: center; justify-content: space-between; justify-content: space-around; justify-content: space-evenly;

Alineación en el eje principal

📐 align-items

align-items: stretch; align-items: flex-start; align-items: center; align-items: baseline;

Alineación en el eje cruzado

💡 Atajo útil: Usa flex-flow para definir dirección y wrap en una sola propiedad. Ejemplo: flex-flow: row wrap;

Lección 5: Formularios HTML - Interacción con Usuarios

Nivel Intermedio

📋 Elementos Esenciales de Formularios

🏗️ Estructura Básica

<form action="procesar.php" method="post"> <!-- Elementos del formulario --> </form>
📝 Campos de Texto
<input type="text" name="nombre" placeholder="Escribe tu nombre" required>

type="text", type="password", type="email", type="tel"

🔘 Radio Buttons
<input type="radio" name="genero" value="hombre"> Hombre <input type="radio" name="genero" value="mujer"> Mujer

Mismo name para agrupar, solo uno seleccionable

✅ Checkboxes
<input type="checkbox" name="intereses" value="deportes"> Deportes <input type="checkbox" name="intereses" value="musica"> Música

Múltiples selecciones posibles

🎯 Validación HTML5

✅ required

<input type="text" name="nombre" required>

Campo obligatorio - no se puede enviar el formulario si está vacío

📏 minlength y maxlength

<input type="text" name="usuario" minlength="3" maxlength="20">

Longitud mínima y máxima del texto

🎯 pattern (expresiones regulares)

<input type="text" name="codigo" pattern="[A-Z]{3}[0-9]{3}">

Patrón específico que debe cumplir el valor

📊 min, max y step

<input type="number" name="edad" min="18" max="100" step="1">

Para campos numéricos - valores mínimo, máximo y incremento

🔘 Tipos de Botones en Formularios

📤 Submit

<input type="submit" value="Enviar"> <button type="submit">Enviar</button>

Envía el formulario al servidor

🔄 Reset

<input type="reset" value="Limpiar"> <button type="reset">Limpiar</button>

Borra todos los datos del formulario

🎯 Button

<input type="button" value="Click"> <button type="button">Click</button>

Botón genérico sin acción por defecto

💡 Validación del lado del cliente: HTML5 proporciona validación automática. Usa JavaScript para validaciones más complejas o personalizadas.
